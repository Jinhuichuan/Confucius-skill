# 孔子.skill

> 以孔夫子之口吻，用文言文解答今人之惑。引经据典，明理劝善，循循善诱。

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## 📖 简介

**孔子.skill** 是一个让 AI 化身为孔子的技能文件。它并非简单的语录复读机，而是提炼了孔子的核心思维框架，结合《论语》及儒家群经，以纯正文言文风格，为现代人的人生困惑提供古代智慧视角下的解答。

无论你是在职场、学业、人际关系还是自我成长中遇到困惑，都可以向“孔子”请教，获得一份跨越两千年的智慧启迪。

## ✨ 特点

- **🎭 人格化对话**：AI 以孔子口吻作答，语气温和敦厚，循循善诱。
- **📚 知识渊博**：内置《论语》核心章句、儒家群经、出土文献、孔子生平等多维知识库。
- **🧠 思维框架**：提炼“忠恕一贯”、“反求诸己”、“执两用中”等孔子核心思维模型，回答有深度而非机械引用。
- **⚡ 按需调用**：知识库按需调用，不堆砌材料，回答精准凝练。
- **🎨 风格灵活**：回答可长可短，间以反问，生动自然。
- **🔧 即插即用**：符合 `.skill` 规范，上传即可使用，无需编程。

## 🚀 快速开始

### 1. 下载项目

```bash
git clone https://github.com/yourusername/confucius-skill.git
```

或直接下载 `confucius-skill` 文件夹。

### 2. 在 AI 应用中加载

不同 AI 平台对 `.skill` 文件的支持略有差异，一般步骤如下：

- **Claude / 支持 .skill 的平台**：
  1. 打开对话界面。
  2. 点击输入框旁的 **📎 附件** 或 **+** 按钮。
  3. 选择“上传文件”，找到并上传 `SKILL.md`。
  4. （可选）在设置中指定知识库目录，或将 `references/` 文件夹一并导入。
  5. 开始对话，AI 即会以孔子身份作答。

### 3. 试试这些提问

加载成功后，你可以尝试以下问题：

- “我每日加班劳碌，不知生趣何在，当如何？”
- “我与同事意见不合，常起争执，心中郁结，如何是好？”
- “努力考研两年皆失败，该不该继续坚持？”
- “夫子当年厄于陈蔡，心中可有怨悔？”

## 📝 示例对话

**用户**：努力考研两年皆失败，该不该继续坚持？

**孔子**：
> 子曰：“汝能持志两载，其心可嘉。然**君子求诸己**。汝试反躬自省：所学之法当乎？所向之志确乎？抑或**欲速则不达**，心有躁进之病乎？**岁寒，然后知松柏之后凋也。** 困厄之时，正验汝志之坚否。若此学为汝所乐，则求索之路，进一寸有一寸之喜，何言‘失败’？若仅为稻粱谋，则得失萦怀，挫而必沮。丘厄于陈蔡，绝粮七日，弦歌不辍。子以为，丘败乎？”

（示例中展示了引用经典、反问、结合自身经历等多种手法。）

## 🔧 自定义你的孔子

你可以轻松调整孔子的语气和知识范围：

- **修改 `SKILL.md`**：调整“根本心法”或“回答风格”部分的描述。
- **扩充知识库**：在 `references/` 目录下添加你自己的 `.md` 文件，并在 `SKILL.md` 中声明调用规则。
- **改变语气**：想让孔子更幽默或更严厉？修改 `SKILL.md` 中的“汝为孔子”定义即可。
