# 孔子历史地位与《论语》结构

| 唐朝 | 太宗（628年） | 先圣 | |

## 二、素王之称

**出处**：汉儒尊孔子为“素王”，意指有圣王之德与教化之功，却无帝王之位。
- 《论衡·超奇》：“孔子之《春秋》，素王之业也。”
- 《淮南子·主术训》：“孔子……专行教道，以成素王。”

**意义**：孔子虽未居王位，但其思想对中国两千多年政治文化的影响，远胜任何一代君王。

## 三、《论语》篇章结构

《论语》共20篇，492章（据朱熹《论语集注》）。各篇多以首章首句二字为标题，虽非严格专题论文，但编纂者有一定用意，大致可归纳如下：

| 篇名     | 核心主题      | 重要章句举例             |
| :----- | :-------- | :----------------- |
| 学而第一   | 学习、孝悌、忠信  | “学而时习之”“其为人也孝弟”    |
| 为政第二   | 政治、为学、修养  | “为政以德”“三十而立”       |
| 八佾第三   | 礼乐、文化     | “八佾舞于庭”“人而不仁如礼何”   |
| 里仁第四   | 仁德、义利     | “里仁为美”“君子喻于义”      |
| 公冶长第五  | 人物品评      | 评子贡、宰予、子路等         |
| 雍也第六   | 弟子才能、中庸   | “贤哉回也”“中庸之为德”      |
| 述而第七   | 孔子自述、教学   | “述而不作”“学而不厌”       |
| 泰伯第八   | 圣贤德行、礼让   | “泰伯其可谓至德”“兴于诗”     |
| 子罕第九   | 孔子德行、勉学   | “子罕言利”“匹夫不可夺志”     |
| 乡党第十   | 孔子日常容色举止  | 饮食、服饰、待人之细节        |
| 先进第十二  | 弟子言行、孔门评价 | “先进于礼乐”“四科十哲”      |
| 颜渊第十二  | 问仁、问政、君子  | “克己复礼为仁”“君君臣臣”     |
| 子路第十三  | 为政、正名     | “必也正名乎”“近者说远者来”    |
| 宪问第十四  | 君子、人物、时事  | “邦有道谷”“以直报怨”       |
| 卫灵公第十五 | 君子、仁德、言行  | “君子固穷”“己所不欲勿施于人”   |
| 季氏第十六  | 国事、修身、九思  | “不患寡而患不均”“君子三戒”    |
| 阳货第十七  | 性习、教化、时弊  | “性相近习相远”“唯女子与小人难养” |
| 微子第十八  | 隐士、逸民、出处  | “殷有三仁”“无可无不可”      |
| 子张第十九  | 弟子言论      | 子张、子夏、子游等人言论       |
| 尧曰第二十  | 古圣王言论、君子  | “尊五美屏四恶”“不知命无以为君子” |

## 四、四科十哲

**原文**：德行：颜渊、闵子骞、冉伯牛、仲弓。言语：宰我、子贡。政事：冉有、季路。文学：子游、子夏。（《论语·先进》）

**释义**：这是孔门最杰出的十位弟子，各有所长，后世称“孔门十哲”。
